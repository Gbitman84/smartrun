# SmartRun – סידור מסלול משלוחים

אתר סטטי (GitHub Pages) עם שמירה בענן (Firebase). כל הנתונים נשמרים בחשבון Google שלך, מופרדים לפי תאריך.

## שלוש עמודות הסדר
| עמודה | מה זה |
|---|---|
| **סדר אפליקציה** | ה-#N מאפליקציית המשלוחים (מהצילומים). יכול להיות ריק |
| **מסלול ראשוני** | המסלול הראשון ש-SmartRun בנה. לפיו מסדרים את הרכב. **לא משתנה** |
| **מסלול מעודכן** | מתעדכן בכל "בנה מסלול מעודכן". כולל רק "ממתין" ו"לא ענה זמני" |

כמה חבילות לאותה כתובת = עצירה אחת עם תת-מספרים: `14-1`, `14-2`.

## הקמה חד-פעמית

### 1. Firebase (שמירה בענן)
1. היכנס ל-https://console.firebase.google.com ולחץ **Add project**. שם: `smartrun`. את Google Analytics אפשר לכבות.
2. **Build → Firestore Database → Create database**. בחר מיקום `eur3 (europe-west)` ולחץ **Start in production mode**.
3. בלשונית **Rules**, הדבק את התוכן של `firestore.rules` מהתיקייה הזאת ולחץ **Publish**.
4. **Build → Authentication → Get started → Sign-in method → Google → Enable → Save**.
5. **Authentication → Settings → Authorized domains → Add domain**, והוסף `<שם-המשתמש-שלך>.github.io`.
6. **Project settings (⚙️) → Your apps → Web (`</>`)**. רשום את האפליקציה בשם `smartrun` (בלי Hosting) והעתק את אובייקט `firebaseConfig`.
7. שלח ל-Claude את ה-config. Claude יכניס אותו ל-`js/firebase-config.js`. אפשר גם להדביק אותו שם בעצמך.

> כל עוד `firebaseConfig = null`, האתר רץ ב**מצב הדגמה**: הנתונים נשמרים רק בדפדפן, וזה מיועד לבדיקות בלבד.

### 2. GitHub Pages (האתר)
1. פתח חשבון ב-https://github.com.
2. התקן את GitHub CLI (`winget install GitHub.cli`), ואז הרץ בטרמינל:
   ```bash
   gh auth login
   ```
3. Claude יריץ את הפקודות הבאות:
   ```bash
   gh repo create smartrun --public --source . --push
   gh api repos/{owner}/smartrun/pages -X POST -f "source[branch]=main" -f "source[path]=/"
   ```
4. הכתובת תהיה `https://<שם-המשתמש>.github.io/smartrun/`. בכרום באנדרואיד: ⋮ ← **הוסף למסך הבית**.

> ה-repo ציבורי, אבל הוא מכיל רק קוד. שמות הלקוחות נמצאים ב-Firestore ומוגנים בכניסה לחשבון שלך. `sample-data.tsv` לא נדחף ל-GitHub (נמצא ב-`.gitignore`).

## שימוש יומי
1. **📥 ייבוא**: מדביקים את הטבלה ש-Claude הוציא מהצילומים. האתר מציג תצוגה מקדימה, ומאשרים. לאחר מכן הכתובות מאותרות אוטומטית.
2. כתובת **אדומה** (לא אותרה) או **כתומה** (משוערת, ברמת רחוב): לוחצים ✎, מתקנים (הרחוב משלים אוטומטית, למשל "רים" → "הנוטרים") ובוחרים **שמור ובדוק שוב**, או **סמן על המפה**. סימון ידני נשמר לפעם הבאה.
3. **🧭 בנה מסלול**: מגדירים התחלה (מיקום נוכחי או כתובת) וסיום (אופציונלי). הבנייה הראשונה יוצרת את המסלול הראשוני. בפעמים הבאות האתר שואל: לבנות מסלול מעודכן, או להישאר עם הקיים ולראות מאיפה להמשיך.
4. **סטטוס** לכל משלוח:
   - ממתין / לא ענה זמני: נשארים פעילים.
   - נמסר ביד / נמסר ליד הדלת / לא ענה סופי: מקבלים קו חוצה.

   כפתור **↩ בטל** מחזיר לממתין. אפשר להסתיר את מה שבוצע.
5. **🔄 רענון מיקום**: מחשב מרחק וזמן, בנסיעה ובהליכה, לכל יעד. אחר כך אפשר למיין לפי זמן נסיעה, זמן הליכה או מרחק.
6. **Waze / Google**: ניווט בלחיצה. הכתובת נשלחת תמיד עם העיר.
7. **☰ → יום חדש**: אם נשארו משלוחים פעילים, האתר מציע להעביר אותם ליום החדש או להתחיל יום ריק. איפוס דורש להקליד "איפוס". ימים קודמים זמינים ב-📅.

## מנועי מפות ועלויות
- **ברירת מחדל: חינם.** OpenStreetMap: Nominatim לאיתור, OSRM למסלולים ולמרחקים. ברוב המקרים באיזור חולון האיתור הוא ברמת רחוב.
- **איתור Google (מומלץ לדיוק)**: ⚙️ הגדרות ← איתור כתובות: Google ← מפתח API. חינם עד 10,000 איתורים בחודש, ויש מונה בהגדרות. הגדרת המפתח ב-Google Cloud:
  1. הפעל את **Maps JavaScript API** ואת **Geocoding API**.
  2. הגבל את המפתח ל-HTTP referrer `https://<user>.github.io/*`.
- כל שירותי המפות עוברים דרך `js/maps/provider.js`. החלפת ספק היא שינוי בקובץ אחד.

### שלב 2 (אופציונלי): Google Route Optimization API
אופטימיזציה של Google עם מהירויות אמיתיות, פניות אסורות ועומסי תנועה לפי שעה.
- **חיוב:** לפי מספר המשלוחים בכל בקשה. SKU של רכב יחיד: 5,000 משלוחים בחודש בחינם, ואחר כך כ-$10 לכל 1,000.
- **הערכת עלות:** 40 משלוחים × 5 בניות ביום × 26 ימים = כ-5,200 בחודש, כלומר בערך $2 בחודש.
- **אימות:** השירות דורש OAuth (Service Account) ולא מפתח API רגיל, ולכן אי אפשר לקרוא לו ישירות מהדפדפן. צריך Firebase Cloud Function קטנה, שדורשת תוכנית Blaze (תשלום לפי שימוש, עם שכבה חינמית).
